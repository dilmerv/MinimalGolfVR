# ⛳ Minimal Golf VR

This prototype was converted to VR using Meta Muse Code (w/ the Muse Spark 1.2 Contributor model) + Unity CLI + MetaVR CLI. It demonstrates what can be achieved through agentic workflow features alone, and how the MetaVR CLI exposes knowledge to accelerate VR developers' workflows.

## How to run this project?
It’s very simple: clone it, open it in Unity, activate the Meta XR Simulator, hit Play, and you’re done! You can use controllers to play the game and the arrow keys on your keyboard to move around & pull the ball back to hit the golf ball.

## 💻 What stack was used to build this?

- [Meta Muse Code](https://developer.meta.com/ai/products/muse-code)
- Unity 6+ LTS
- [Meta XR Core SDK](https://developers.meta.com/horizon/downloads/package/meta-xr-core-sdk)
- [Meta XR Interaction SDK](https://developers.meta.com/horizon/downloads/package/meta-xr-interaction-sdk-ovr-integration/)
- Meta XR Simulator [win](https://developers.meta.com/horizon/downloads/package/meta-xr-simulator-windows/) | [macOS](https://developers.meta.com/horizon/downloads/package/meta-xr-simulator-mac-arm)
- [Unity CLI](https://docs.unity.com/en-us/unity-cli/use-unity-cli)
